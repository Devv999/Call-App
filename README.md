# Call-App
Local Messenger 📡 is an offline, local-only voice calling app for nearby users 🏘️. It discovers devices via Bluetooth 🔵 and connects using Wi-Fi Direct 📶 for real-time calls with no internet or SIM 🚫🌐📵. Built for communities, campuses, and emergencies 🆘🎓, it’s private 🔐, fast ⚡, and works even in airplane mode ✈️.
