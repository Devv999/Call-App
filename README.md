# 📞 Call App

**Call App** is an offline, local-only voice calling Android application designed for nearby users. It enables real-time voice communication using Bluetooth and Wi-Fi Direct — without internet, SIM cards, or mobile data.

Built for communities, campuses, neighborhoods, and emergency situations, Call App focuses on privacy, speed, and reliability.

---

## ✨ Features

- 📡 Local-only voice calling (no internet required)
- 🔵 Automatic nearby user discovery via Bluetooth
- 📶 High-quality calls using Wi-Fi Direct
- 🎙️ Real-time two-way voice communication
- 🆘 Works in emergencies & airplane mode (Wi-Fi enabled)
- 🔐 Privacy-first (no data leaves your device)
- 📱 Responsive UI for all screen sizes
- 🌙 Light & Dark mode support

---

## 🧠 How It Works

1. Devices discover each other using **Bluetooth Low Energy (BLE)**
2. A secure local connection is established via **Wi-Fi Direct**
3. Voice data is transmitted using **local WebRTC**
4. No cloud, no servers, no tracking — fully offline

---

## 🛠️ Tech Stack

- **Platform:** Android (Android 10+)
- **Language:** Kotlin
- **Architecture:** MVVM
- **UI:** XML + Material Design 3
- **Discovery:** Bluetooth Low Energy (BLE)
- **Networking:** Wi-Fi Direct
- **Calling:** WebRTC (local-only)
- **Background Calls:** Foreground Service

---

## 🔒 Privacy & Security

- ❌ No internet usage
- ❌ No ads or analytics
- ❌ No user tracking
- ✅ All communication stays on local devices
- ✅ Permissions are used only for core functionality
